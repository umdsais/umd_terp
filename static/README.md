# Modified ICL

This project uses a modified version of the ICL mainly consisting of override styles. This is used in conjunction with the University of Maryland [web components library](https://playground.designsystem.umd.edu/)

## Installation

Dependencies need to be installed with [node/npm](https://docs.npmjs.com/getting-started/installing-node).

`nvm use`

`npm install`

## Development

### Watch mode

`npm run watch`

## Building for production

To build your code for production, run the following:

`npm run build`
